# cpp-management-systems
Collection of C++ projects demonstrating basic management systems, CRUD operations, and data handling.

**Projects**

**1. Contact Management System**
A console-based application developed using C++ for managing contact information.

Features:
1. Add new contacts
2. View a list of all contacts
3. Search for a contact
4. Edit existing contact details
5. Delete contacts

**2. Employee Record System**
A console-based application developed using C++ for managing employee records through a menu-driven interface.

Features:
1. Add new employee records
2. View a list of employee records
3. Modify existing employee records
4. Delete employee records
